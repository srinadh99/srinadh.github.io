# Personal Website Starter (GitHub Pages)

A minimal, clean one‑page site with a dark‑mode toggle and sections for About, Research, Projects, Blog, and Contact.

## Quick start (GitHub Pages)

1. Create a new repo named **`USERNAME.github.io`** (replace with your GitHub username).
2. Download this ZIP and extract it. Drag all files into the new repo and commit.
3. In the repo **Settings → Pages**, set **Branch: `main`** and **Folder: `/ (root)`**.
4. Your site will be available at `https://USERNAME.github.io`.
5. Edit `index.html` to update your bio, links, and projects. Add posts in `/blog`.

## Customize

- Replace placeholders in `index.html` (GitHub, Scholar, ADS, ORCID, email).
- Add your own images into `assets/img/` and update the `<img>` `src` attributes.
- Tweak styles in `assets/css/style.css`.
- For a custom domain, add a `CNAME` file at the repo root with your domain.

## Notes

- This starter is framework‑free (pure HTML/CSS/JS).
- Dark mode settings persist with `localStorage`.
- Works on GitHub Pages without any build steps.
